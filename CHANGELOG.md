# Changelog

ClaudeMaxxing follows [Semantic Versioning](https://semver.org): a new **major** version changes how it installs or what it keeps on your PC in a way that needs you to act, a **minor** one adds tools or options, a **patch** one fixes things. The version lives in `lib/common.ps1` (`$AppVersion`) and must match the newest entry here; pushing the tag `v<version>` publishes a GitHub Release with the ZIP to install (`.github/workflows/release.yml`). What counts as each kind of change, and how to release, is in [VERSIONING.md](VERSIONING.md).

## Unreleased

- **Call a session from the phone**: each session's page has a call button. With the phone locked and headphones on you talk, Claude checks it and says its proposal, two taps accept it, three answer, and it speaks again when it finishes or asks something. It writes through the same inbox as the chat, so permission prompts stay on the PC.
- **The phone app takes only the certificate its QR pinned**, also when another one comes from an authority the phone trusts. Update the app; nobody has to pair again.
- **Your account in the window and on the phone**: name, plan, email and organization, at the top of Home and of the phone's panel, read from Claude Code's `~/.claude.json`.
- **The session's status line on the phone**: under each session's name, the folder, the branch (with the worktree when it is in one) and the environment, then the model with its effort, the context used, the cost and the time it has run. The statusline block saves them per session, only when they change.
- **Its own names and logo, not Anthropic's**: Claude Whip, Claude Whisper and Claude Judge are now **Maxx Whip**, **Maxx Whisper** and **Maxx Judge**; the tray icon, the usage popup and the Explorer menu (now listed as *ClaudeMaxxing*) show the ClaudeMaxxing jellyfish instead of the Claude logo, and the installer no longer copies icons from the Claude app (it deletes the ones older versions copied). The menu still says *Abrir con Claude Code*, because that is what it opens.
- **Claude Whip respects its threshold**: the forecast no longer turns it on before "From 85%" unless you switch on **Before the threshold, if it will run out** (new, off by default) in its section.
- **Session symbol**: Settings, on the PC and on the phone, picks the symbol that stands for each session (the egg by default), one per PC. Egg and Drop for now. A change on either side shows on both and redraws the taskbar, the strip, the window and the phone; the sessions already open keep theirs in the tab and the statusline, and each new one starts with the one chosen. Adding one takes one image (`font/add_symbol.py`). Claude Code > Icon of each session is now called Icon position.
- **Voice notes on the phone**: what the sessions' voice says is saved on the phone and shows in each chat as a WhatsApp-like voice note (play, pause, seek, 1×/1.5×/2×, the text underneath). The headphones icon lists every one kept, also after its session closed. The PC sends them from the voice's history (`/voices`, `/voice`), which now keeps the last 100.
- **Phone app** (`mobile\`, Flutter, Android): the ClaudeMaxxing panel on the phone and the sessions open on the PC, one page each, swiping sideways, with their conversation live and a box to write to them. It pairs by scanning the QR in the new **Celular** section; the tray answers over HTTPS on your network or Tailscale with a certificate the QR pins (`lib\mobile.cs`, `lib\mobile.ps1`), with no server in between. The panel is the window's sections described by the PC, so its switches and choices are the window's own. Text reaches a session through Claude Code's cross-session inbox, which the voice plugin records when the session starts. Off until you turn it on; off by default in the business edition.
- **The phone app's Power section**: darken the screen (black on every screen, the brightness at its lowest and the PC kept awake, so the sessions and the network go on; Esc on the PC ends it) and shut down the PC (the phone asks first; Windows waits a minute, and Cancel the shutdown stops it). Switching environment from the phone no longer opens a question on the PC that nobody could answer: the phone asks.
- **The phone's chat looks like a chat**: bubbles (yours on the right), the hour under each, the day between days, light Markdown (code, bold, lists) and each run of tool calls folded into one line that opens with a tap. Pinch it, or use the slider in Chat style, to make the text larger or smaller; Chat style also has eight palettes, one in the session's color. The phone keeps both.
- **New session first in the phone's panel**: one button, pick the root folder of an environment or one of the PC's recent folders and the Claude Code session opens (it left Inicio, where it repeated).
- **Skills & MCP catalog**: about 430 third-party skills (anthropics/skills, obra/superpowers, wshobson/agents and affaan-m/ECC, copied as text at a pinned commit: no scripts, hooks or tool grants) and 16 official MCP servers, all off. Switching off removes only what ClaudeMaxxing added.
- **One list of skills and one of MCP servers**, yours and the catalog's together, with a switch each and a search box (type to filter, Esc clears it). Your own skills switch off with `skillOverrides` (the setting `/skills` uses); one of your MCP servers switched off is kept by ClaudeMaxxing and removed, then added back when switched on.
- **Each environment with its own list**: Ambientes has a Skills y MCP tab with a card per environment and what its sessions load. Its first change gives an environment its own list, and its folder then loads exactly that list: every other skill off and every other MCP server blocked, through its `.claude\settings.local.json`.
- **The ClaudeMaxxing window opens like a session**: on the first half, quarter or screen no session holds, as set in Claude Code > Por pantalla.
- **1, 2 or 4 sessions per screen**: Claude Code > Por pantalla places each new session on the whole screen, a half or a quarter. ClaudeMaxxing measures how much of the time your open sessions are working (from the tray's eggs, kept for 30 days in `activity.json`) and, after an hour of sessions, recommends how many per screen: agents that work half the time or more rarely wait for you, so 4 fit; ones that work under a fifth of it mostly wait for you, so 1 shows more of each.
- **Snip to Claude Code**: Win+Alt+C (Win+Shift+X or Ctrl+Alt+C when another app holds it) is a snipping tool like the Windows one, with a toolbar: picture or video; rectangle, window (the window itself, even where covered), full screen or freeform; draw (five colors, three widths, highlighter, undo); color picker; extract text (Windows OCR). A picture is copied and saved in Pictures\Screenshots (a recording, in Videos\Screen Recordings), and a panel next to it asks for a prompt and a folder (the environment on in Ambientes by default); Enter or Enviar opens a session there with the image. A video (Media Foundation: H.264 with the pointer, AAC from the speakers and the microphone) has a countdown, pause and stop, and goes to Claude with a few of its frames. After a Win+Shift+S snip, the same panel shows up in the corner. Off in Configuración > Capturas.
- **English**: the ClaudeMaxxing window, the tray, its notifications and the other windows (Agendar sesión, Otros PCs, Claude Whisper, Claude Judge) are now in English, the default. Switch to Spanish in the new **Configuración** section (last in the side menu). Each language is one file in `lib/lang`, so adding another is translating a copy of `en.json`.
- **The ClaudeMaxxing window goes full screen** with the maximize button (between minimize and close, like Windows), or F11 (Esc or F11 leaves it). The window is drawn at the screen's size, so the text stays sharp.
- **Inicio has shortcuts to the sections you open most**, next to its title (until you have used it for a while, Uso y agenda, Claude Code, Estadísticas and Voz).
- **Claude Code explains Peek**: a link at the bottom of the section shows what hovering over a path, clicking it and right-clicking it do with files and images in Claude's answers.
- **Ambientes explains how to create one**: a new install starts with none, and the section shows a prompt to copy into Claude Code. The prompt has Claude read your usage, projects and sessions, propose the environments, ask about what it can't tell, write each `.json` and check it with a preview that closes nothing. **Crear con Claude** copies the same prompt once there are environments. Ambientes' README and an example environment are now installed, so the prompt can point to them.
- **Claude Whip's icon is a whip.**
- **PDFs cost less of the plan**: a new plugin with a skill has Claude read a PDF as Markdown with PyMuPDF4LLM instead of as page images. The installer puts PyMuPDF (AGPL-3.0, about 250 MB) in `pdf\venv`.
- **Versioning policy** in `VERSIONING.md`: what counts as major, minor and patch, and how to release. A release must be tagged on `main` (or a `release/*` branch) and have a changelog entry.

- **Claude Whip follows the forecast**: past half the 5-hour window, if it is on pace to run out before it resets, Whip comes on before its threshold and says at what time the limit would come. The shell guard is tighter (a lone `&`, extra lines, `$(...)`, backticks, `git -c`/`config`/`apply`, `sort -o`, `VAR=` prefixes, a `whip-check.sh` planted in the repo) and MCP tools that run code or write are blocked. The check stops a test command after 20 minutes.
- **Claude Whip shows each agent's account**: the email, the plan (ChatGPT Plus, Copilot Free...) and until when, from each CLI's own login files; Copilot's plan comes from `gh api`, refreshed every 6 hours.
- **The voice says when the plan ran out** and at what time it comes back.
- **Opt-in**: Otros PCs sets up nothing on a new install until **Activar** (or `install.ps1 -Bridge`); environment detection stays off until you turn it on, and never runs without environments.
- **Claude Whisper** asks once, before the first listen, after saying that the transcription is an undocumented service and that the call's audio goes to Anthropic; calls older than 30 days are deleted.
- **Business**: the policy can also turn off Ambientes (off by default) and Claude Judge; a changed policy applies within 5 minutes; the Whip plugin reads IT's policy itself.
- **Security fixes**: `get.ps1` no longer installs the unverified `main` branch when GitHub's API fails; **Permitir 1 hora** no longer allows requests already waiting, and a command too long to show can only be refused; Peek shows programs and scripts in Explorer instead of running them; a paired PC whose user has an apostrophe no longer breaks every `ssh`; the tamper check covers `sshd_config` and the gate.
- **Fixes**: after `/clear` a session no longer lists itself among the other sessions; JSON state is written atomically and `history.json`/`cloud.json` under a lock; updates now refresh the statusline block; the window fits 1366x768 screens; uninstall gives back the exact theme; money and times follow one Spanish format; keys are stored encrypted (DPAPI); scheduled runs find Claude Code after it moved.
- **CI** runs the Whip and Peek tests and draws every window; a release runs the whole CI.
- **Updates in one click**: the tray tells you when a new version is out and installs it, checking its SHA-256 and keeping what you installed without (**Check for updates...** in its menu looks right away; the business edition only looks when asked). The phone app tells you too and downloads the new APK, which each release now publishes signed as `ClaudeMaxxing.apk`.

## 1.1.0 - 2026-11-08

- **Business edition**: `install.ps1 -Business` (or `--business`; `-Personal` is the default and switches back). The choice is kept on update, and a policy that IT puts in `%ProgramData%\ClaudeMaxxing\policy.json` makes the PC business. A new **Empresa** section shows:
  - the seat report: 30-day use, the API-equivalent cost against the seat price, and whether the seat falls short, fits or has room;
  - reports for a shared folder (by hand, or every 7 days) and the team's summary as a CSV;
  - the company's objectives, which Claude Judge weighs in every trial;
  - the team kit of plugins and marketplaces, installed with one click.
- The company policy (`business\policy.example.json`) turns modules off: FreeLLMAPI, Otros PCs and Claude Whisper are off by default. A module that is off disappears from the tray and the window and does not start; turning Otros PCs off also removes its firewall rules and `~/.ssh/config` block.
- **Debates** in Otros PCs: **Debatir con <PC>...** has your Claude and the other person's argue a decision, each from its own project, and gives you both one recommendation. A blind first round, two replies, and a moderator with no files on the PC that started it. Each Claude only reads the folder its person picks (`claude -p --restricted`, Read/Glob/Grep, no `.env` or keys); only text crosses, through a new mailbox mode of the gate that runs nothing; keys are hidden before anything is sent. The other PC accepts each debate on its own: an hour grant does not open one.

## 1.0.0 - 2026-11-07

First public release. Install with one command: `irm https://raw.githubusercontent.com/SantiagoRuizM/ClaudeMaxxing/main/get.ps1 | iex` (or `npx github:SantiagoRuizM/ClaudeMaxxing`, or the ZIP and `install.ps1`; see the README).

- **Usage tray**: the 5-hour window and the weekly limit of your Claude plan in the notification area, with when each resets, a warning at 80 % and 95 %, and the ClaudeMaxxing window with every tool.
- **Skills y MCP**: every skill and MCP server Claude Code loads, and Anthropic's packages to create skills, MCP servers and plugins.
- **"Abrir con Claude Code"** in the Explorer menu: each session in its own half of a screen, with its own color and name.
- **Voice**: a spoken one-line summary of every answer, a voice and a musical signature per session (Edge, ElevenLabs, Gemini or the Windows voice).
- **Agenda**: scheduled and automatic sessions on this PC (Task Scheduler) or in the cloud, and a week plan that spreads the weekly limit.
- **Planear sesión**: Claude Judge puts the day's idea on trial before you start.
- **Estadísticas**: hours, consumption per 5-hour window with a forecast, schedules, projects, models and tools, from Claude Code's own transcripts.
- **Ambientes**: work environments that open and close apps, folders, servers and Chrome tabs, with detection of the one you are in.
- **Otros PCs**: PCs on the same network find each other, pair once, and open terminals or Claude Code on each other.
- **Claude Whisper**: a live copilot for calls.
- **Peek**: every path in Claude's replies becomes a link with a preview (image, video frame, PDF page, audio length, folder, code with `path[from:to]` ranges), and each reply lists its references.
- **FreeLLMAPI** sessions when the plan runs out, and **context-mode** to save context.
